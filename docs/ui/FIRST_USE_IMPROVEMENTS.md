# 首次使用体验改进

## 第五轮体验改进（2026-09-17）

- 负责人筛选器随列表 URL 重建，清除筛选、切换范围及浏览器历史导航后，以当前页面条件为准，不重新提交旧的本地选中值。
- 范围切换保留关键词、状态和兼容的负责人条件，清除游标及新建模式。未分配范围不显示负责人选择器，解释如何查找指定成员；携带冲突负责人参数的 GET 地址规范化后再查询，不改变 Session。
- 任务配置返回路径允许携带经过限制的列表上下文。列表路径必须属于同一工作空间，只保留受支持的筛选、游标及任务行锚点；拒绝外部站点和任意页面返回。流程、智能体和组织模型配置沿用已有参数传递，返回原任务后可继续返回原筛选列表。
- 五步导航使用“当前页面”及页面位置语义；明确下一待办由下方提示说明。已有资源不代表连接检查、发布或业务验收全部完成，不新增虚假的检查通过状态。

### 第五轮验证

- Web 类型检查无错误或警告，214 项 Web 测试通过，3 个修改的 Svelte 文件 autofixer 无问题。Web 镜像构建成功并更新到 3000。
- Owner 浏览器实测：范围切换保留关键词和状态；负责人筛选后清除，控件恢复全部，再次提交不带回旧成员；未分配范围不再出现负责人选择器。
- 实测搜索列表 → 任务 → 流程 → 组织供应商配置 → 原任务 → 列表，关键词及原任务锚点保留。手工输入未分配与指定负责人的冲突 URL 后，地址自动移除冲突参数，任务仍显示。
- 单元测试覆盖分页重置、兼容条件保留、跨配置动作传递及外站/跨工作空间嵌套返回限制。本轮未新增或修改业务记录、供应商密钥，未进行真实模型运行及全角色或生产验收。

## 第四轮体验改进（2026-09-17）

- 新建工作项保留本页内存草稿。关闭、Esc、遮罩关闭统一提醒；重新打开保留标题、描述、优先级、负责人及高级输入。明确放弃或确认离开才清空，刷新和关闭页面提示未保存。增强表单在校验失败时保留输入，抽屉内展示错误，放弃时清除旧错误。
- 详情返回原工作空间列表时保留范围、关键词、状态、负责人和游标，用原任务锚点定位。编辑、状态更新及验收提交后的详情跳转也保留返回上下文。安全解析拒绝跨站、跨工作空间和非列表路径；直接打开详情则返回默认列表。定位不承诺精确像素恢复。
- 1280px 以下使用紧凑任务行，直接显示状态、优先级和负责人，宽屏保持表格。
- 配置页面共用供应商、模型检查、智能体、流程、运行验收五步导航，标识当前步骤及当前页面可确认的已有配置，提供继续入口。复用现有表单和显式发布，不自动创建或运行资源。
- 工作项突出与阶段匹配的下一步；没有可验收运行时显示“暂不可验收”。工作空间选择页改用中文业务角色和状态，不再展示 Session 实现说明，安全 POST 选择保持不变。
- 浏览器回归的相关文案选择器同步更新，保留该文件此前的未提交改动。

目标：从工作台进入模型配置、Agent、流程、工作项及人工验收，避免要求新用户先理解内部标识。

## 页面行为

- 工作台按模型、已发布 Agent、已发布流程展示准备状态及负责角色。读取失败或分页无法判定时显示“暂时无法确认”，不当作未配置。模型“已配置”不代表调用已验证。
- 需求整理模板预填 Agent 草稿指令和示例工作项，不自动保存、发布、启用工具或调用模型。
- 工作项负责人可按姓名或邮箱筛选。沿用现有 Owner 成员目录权限；无目录权限时提供本人选项。列表截断或不可读取时保留高级成员标识输入，不放宽后端权限。
- 外部来源与 JSON 输入默认折叠。来源类型和引用成对填写的规则不变。
- 运行页按标题筛选最近 50 个工作项，明确说明范围。更早的任务仍从工作项详情进入关联运行；这不是全量搜索。
- 资源空状态根据组织或工作空间显示范围，提供配置指引或重试入口；任务和运行筛选可清除。
- 流程页面展示业务路径；工作项承载本次执行结果和人工验收，运行页面保留技术记录。该展示不是可拖拽 BPMN 编辑器。
- 供应商保存后沿用已有自动跳转到模型配置的行为；模型页展示接入步骤和保存与调用验证的区别。模型目录支持独立连接检查：使用已保存配置查询供应商 `/models`，检查认证和模型可见性，不发送提示词或执行生成。供应商未提供目录时仍需通过实际运行验证。
- 统一常用状态及导航中文文案，不改变 API 状态值。

## 第三轮体验改进（2026-09-17）

- 工作项编辑收起时保留本页输入；新增取消编辑，放弃修改或离开页面时提醒。提交继续使用原 revision。草稿仅保留在当前页面，不写浏览器持久存储。
- 登录及企业登录表单保留 `return_to` 查询参数，原生登录经过 MFA 后回到原目标；后端继续限制为同源安全路径。
- 主导航在页面导航完成后关闭抽屉，共享抽屉关闭按钮使用中文可访问名称。
- 工作项列表窄窗口直接显示标题、状态、优先级和负责人；宽窗口保持表格。标题搜索由 API 在租户和 Workspace 范围内执行，支持大小写不敏感的字面子串、最多 200 字符，并与现有筛选、游标分页组合。此变更不构成大规模搜索性能验收。
- 工作台优先展示找回任务入口和当前下一步，完整配置说明默认折叠；流程缺少模型时直接引导到模型接入，模型页从任务进入时提供继续配置 Agent 的入口。沿用已有资源表单与显式发布，不自动创建或发布资源。
- 工作项描述保留换行，已取消任务可直接定位状态更新区。

## Agent Studio 会话入口（2026-09-17）

新增 `/:workspaceId/studio`，侧栏 Agent Studio 指向会话工作区。会话是现有领域对象的交互入口，工作项、流程版本、Session 和 Run 仍由原 API 持久化与授权。

- 初始输入选择“创建工作项”或“创建流程草稿”。操作引导将首行作为可编辑标题、保留原文作为描述；明确标记未调用模型、未保存。确认后才创建资源。
- 工作项保存后在同页选择已发布流程并发送，使用原工作项启动 API。后续消息通过 Run API 沿用服务端查到的 Session、流程版本和输入；不相信客户端传入的版本或 Session。
- 消息从 append-only Session Event 读取，100 条分页；最近工作项 20 条游标分页。Run 事件默认折叠，保留 SSE、运行详情、工具审批及成功结果的人工验收入口。
- 流程草稿仅保存名称和描述，后续在既有配置页选择 Agent、权限和预算并发布。当前没有模型自动拆解需求、自动编排流程或在聊天中发布版本。
- 尚未确认的草稿不持久化；已保存工作项与运行可重新打开。侧栏列的是工作项，并非独立聊天记录实体。
- Web 类型检查、Svelte autofixer 和 222 个单元测试通过。真实模型多轮对话仍需在配置了组织模型和已发布流程的环境验收，不能由模拟 API 测试替代。
- 3000 浏览器实测：需求预览、编辑标题、确认创建工作项、刷新恢复、无已发布流程时禁用执行、保存未发布流程草稿及跳转配置页均通过。保留标记为“会话验收 2026-09-17”的一个模拟工作项和一个流程草稿供复查。

## 会话体验改进：草稿与返回上下文（2026-09-17）

本批完成审查建议的第一项，并提前显示第二项的配置准备情况：

- 输入及可编辑草稿自动保存至当前标签页 sessionStorage，按用户、Workspace、工作项/流程和当前 Run 隔离，24 小时过期。只保存白名单业务字段。刷新及配置页面往返可恢复；确认成功或主动放弃后清除。存储失败时显示提示并在离开时保护输入。
- 返回地址校验扩展到 Studio 的 work_item/run/workflow，拒绝外部地址、非白名单参数、重复参数及不完整/冲突组合。配置页、组织模型页与原有步骤导航保持返回原会话入口。
- 工作项详情增加“继续此工作项的对话”。Agent Studio 提升到主导航。
- 会话首页提前显示模型、智能体及流程状态，读取既有 API；读取失败显示无法确认。已有配置不等于连接或真实运行已验证。保留需求整理模板入口。
- 234 个 Web 测试通过，类型检查和全部修改组件的 Svelte autofixer 通过。3000 实测输入刷新恢复、编辑后跨智能体与组织模型页返回、主动放弃后刷新均通过。

仍未完成：真实模型澄清与结构化提案、独立的跨设备会话历史/多对象关联、会话内完整验收。标签页草稿不是服务端持久会话；当前测试组织仍无可用模型和已发布流程，不能据此宣称真实执行验收通过。
