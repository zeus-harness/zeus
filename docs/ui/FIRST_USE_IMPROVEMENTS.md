# 首次使用体验改进

目标：从工作台进入模型配置、Agent、流程、工作项及人工验收，避免要求新用户先理解内部标识。

## 页面行为

- 工作台按模型、已发布 Agent、已发布流程展示准备状态及负责角色。读取失败或分页无法判定时显示“暂时无法确认”，不当作未配置。模型“已配置”不代表调用已验证。
- 需求整理模板预填 Agent 草稿指令和示例工作项，不自动保存、发布、启用工具或调用模型。
- 工作项负责人可按姓名或邮箱筛选。沿用现有 Owner 成员目录权限；无目录权限时提供本人选项。列表截断或不可读取时保留高级成员标识输入，不放宽后端权限。
- 外部来源与 JSON 输入默认折叠。来源类型和引用成对填写的规则不变。
- 运行页按标题筛选最近 50 个工作项，明确说明范围。更早的任务仍从工作项详情进入关联运行；这不是全量搜索。
- 资源空状态根据组织或工作空间显示范围，提供配置指引或重试入口；任务和运行筛选可清除。
- 流程页面展示业务路径；工作项承载本次执行结果和人工验收，运行页面保留技术记录。该展示不是可拖拽 BPMN 编辑器。
- 供应商保存后沿用已有自动跳转到模型配置的行为；模型页展示接入步骤和保存与调用验证的区别。模型目录支持独立连接检查：使用已保存配置查询供应商 `/models`，检查认证和模型可见性，不发送提示词或执行生成。供应商未提供目录时仍需通过实际运行验证。
- 统一常用状态及导航中文文案，不改变 API 状态值。

## 验证边界

前端回归覆盖准备状态、权限错误、分页不确定性、成员选项权限及模板创建后的跳转；真实模型质量、生产验收和全量搜索不在本轮完成范围。

## 本地验证记录（2026-09-16）

- 172 项 Web 测试通过；`pnpm check` 通过；修改的 Svelte 组件 autofixer 无问题；Web 生产构建通过。
- 3000 环境 Owner 账号实际验证：工作台待配置状态、示例工作项预填、姓名/邮箱搜索与选择成员、高级字段折叠、Agent 模板预填、流程业务路径、模型接入说明、组织级空状态与运行页中文状态。
- 未创建新的业务记录、发布 Agent、修改密钥或执行模型调用。当前组织无模型配置，真实运行与验收仍未验证。

## 第二轮体验改进（2026-09-17）

- 工作项可编辑标题、描述、优先级和负责人；提交绑定页面 revision，冲突时保留输入，不覆盖其他人的更新。编辑不会改变工作项状态。
- 工作台和工作项列表新增“我创建的”和“未分配”入口，使用服务端筛选并保留分页条件。
- 工作项进入流程、Agent 和组织模型配置时携带安全的本地返回路径，提供返回原任务入口。
- 详情默认页签根据任务阶段选择：未运行或已取消查看详情，执行中查看活动，有结果查看结果；已取消任务显示恢复提示。
- 组织模型增加独立连接测试，限制 20 秒，展示可操作错误和检查时间；检查绑定模型 revision 和组织管理权限。仅检查目录访问，不等同于生成成功。
- 组织导航采用中文，导航项目保持单行。

### 本轮验证

- `pnpm check`、`pnpm test`、严格 Clippy 通过；最后的 Web 回归为 184 项，修改的 Svelte 页面 autofixer 无问题。
- 9 组隔离 PostgreSQL 集成测试通过。新增模型检查验证组织权限、过期 revision 拒绝、模拟供应商目录成功响应；响应不包含密钥或生成文本；另有回归验证诊断时间为 RFC3339 字符串。
- API 与 Web 本地镜像构建并更新到 3000。Owner 账号实测编辑四项字段、清除负责人、创建者和未分配筛选、取消任务默认详情、流程 → Agent → 组织模型 → 原工作项返回，以及中文导航单行布局。
- 测试工作项已恢复原始内容、普通优先级、未分配负责人，并保持已取消；编辑操作正常增加 revision。
- 当前组织没有模型配置，本轮未执行真实供应商请求、模型生成或人工结果验收。模型连接接口的成功路径由隔离模拟供应商验证，不能作为真实模型质量证明。

## 第三轮体验改进（2026-09-17）

- 工作项编辑收起时保留本页输入；新增取消编辑，放弃修改或离开页面时提醒。提交继续使用原 revision。草稿仅保留在当前页面，不写浏览器持久存储。
- 登录及企业登录表单保留 `return_to` 查询参数，原生登录经过 MFA 后回到原目标；后端继续限制为同源安全路径。
- 主导航在页面导航完成后关闭抽屉，共享抽屉关闭按钮使用中文可访问名称。
- 工作项列表窄窗口直接显示标题、状态、优先级和负责人；宽窗口保持表格。标题搜索由 API 在租户和 Workspace 范围内执行，支持大小写不敏感的字面子串、最多 200 字符，并与现有筛选、游标分页组合。此变更不构成大规模搜索性能验收。
- 工作台优先展示找回任务入口和当前下一步，完整配置说明默认折叠；流程缺少模型时直接引导到模型接入，模型页从任务进入时提供继续配置 Agent 的入口。沿用已有资源表单与显式发布，不自动创建或发布资源。
- 工作项描述保留换行，已取消任务可直接定位状态更新区。

### 本轮验证

- `pnpm check`、`pnpm test`、`cargo fmt --check`、严格 Clippy 通过；Web 共 187 项测试通过，8 个修改的 Svelte 文件 autofixer 无问题。
- 9 组隔离 PostgreSQL 集成测试通过；标题搜索验证大小写不敏感匹配、无结果及百分号按字面处理。API、Web 和 Gateway 镜像构建成功并更新到 3000。
- Owner 账号浏览器实测：收起再展开保留草稿、取消离开保留输入、取消编辑恢复原值；测试工作项未提交修改，保持 revision 4。
- 原生登录及 MFA 后，经安全的 Workspace 选择返回“我创建的”列表，并保留中文标题查询。企业登录仅验证表单目标参数，没有进行真实外部 IdP 登录。
- 实测主导航切页后关闭、470px 窄屏任务信息、中文搜索及清除空结果筛选、描述换行、状态区定位、工作台默认折叠引导，以及流程直接进入组织模型配置并保留返回原任务入口。
- 当前组织没有模型配置；未新增供应商密钥、发布资源、执行模型生成或人工结果验收。模型配置完成后继续 Agent 的入口未在真实已配置组织中实测；本轮不代表生产或大规模搜索性能验收。
